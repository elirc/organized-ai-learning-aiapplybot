# Mission Learning Path

This suite turns the repo into an ordered training campaign. Each mission asks you to trace code, explain behavior, review risk, or design a small change. Do not passively read these. Open the cited files, write answers, and self-grade.

## How The Mission System Works

Every mission has:

- a skill goal
- exact files and line ranges
- chronological code walkthroughs
- a checkpoint
- a self-grading guide
- a connection to the next mission

## Recommended Pacing

Do one junior mission per day at first. For mid-level and senior missions, expect to spend longer because the task is not just "find the code." It is "form a defensible mental model."

## Using Codex Without Losing The Learning

Ask Codex to quiz you, challenge your explanation, or point to files. Do not start by asking for the answer. Use this pattern:

```text
I am on Mission N. I read the cited lines and think X happens. Ask me 3 questions that reveal whether my understanding is wrong. Give hints only after I answer.
```

This suite differs from normal documentation because the output is not a fact list. The output is your improved engineering reflex.
